# 🎙️ AmozVz v1.0.1 — Privacy-First Voice-to-Text AI Agent

**AmozVz v1.0.1** introduces a **zero-sensitive-data** architecture and a signed release build for smooth, warning-free downloads and installation on any Android device.

---

## 🛡️ Privacy & Security Improvements in v1.0.1

- 🚫 **Removed All Sensitive Data Access**:
  - Removed `BIND_ACCESSIBILITY_SERVICE` (no screen reading or keystroke inspection).
  - Removed `SYSTEM_ALERT_WINDOW` (no draw-over-apps permission).
  - Removed `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`.
  - Play Protect and browser downloads now install cleanly with zero security blocks!
- 🔏 **V2 Scheme Release Signed**:
  - Signed using an official V2 APK signing certificate (no generic debug keys).
- 📋 **Instant Auto-Copy & Quick Share**:
  - Polished text is automatically copied to your clipboard the moment you stop speaking.
  - Native 1-tap **Share** button sends text directly to WhatsApp, Slack, Gmail, Telegram, etc.
- 📦 **Optimized APK Size**:
  - Reduced release APK size from 17 MB to **11 MB**.

---

## 🧠 Core Speech Intelligence

- **Hesitation & Filler Removal**: Filters *"um"*, *"uh"*, *"er"*, *"ah"*, *"you know"*, *"basically"*, and repeated stutters.
- **Self-Correction & Speech Changes**: Resolves *"scratch that"*, *"no wait"*, *"make that 3:30 pm"* into your final intended sentence.
- **Spoken Punctuation**: Naturally handles periods, commas, questions, and spoken commands.
- **Dictation Modes**: Natural Flow, Professional, Bullet Points, Raw Verbatim.
- **Offline + Cloud**: Zero-latency on-device processing + optional cloud AI integration.
